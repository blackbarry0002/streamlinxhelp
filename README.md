# Connection Compass

An independent, editorial-style marketing site for Streamlinx Help — a third-party
assistance desk that helps households explore and understand internet, cable,
TV and streaming options. Built as a static single-page app with React,
TanStack Router and Vite.

## Development

Requires [Bun](https://bun.sh).

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

Produces a static `dist/` folder that can be deployed to any static host.

## Preview a production build

```sh
bun run preview
```
